Dynamics Notes

Study notes on model predictive control: the theory of receding-horizon control, how to implement it, and how it is used in agents.

MPC Theory

Model predictive control solves a small optimal-control problem at every time step, applies only its first move, and repeats. This tab builds it up from a linear model to the stability proof.

Core idea

Model predictive control (MPC) is finite-horizon optimal control, re-solved at every time step from the latest measured state. Each step runs the same loop:

  1. Measure the current state x(k).
  2. Predict the system N steps ahead with a model.
  3. Optimize an input sequence u_0, \dots, u_{N-1} that minimizes a cost and respects constraints.
  4. Apply only u_0, discard the rest, and repeat at k+1.

This is the receding horizon principle: the prediction window slides forward with time. Because the plan is recomputed from a fresh measurement every step, MPC is a feedback law, not an open-loop plan. Model error and disturbances are corrected at the next step.

What MPC buys over classical controllers: it handles constraints (actuator limits, safe state regions) explicitly, works naturally for multi-input multi-output systems, and uses preview of future references or disturbances when they are known.

Problem formulation

Standard linear MPC uses a discrete-time linear model and a quadratic cost. The model is

x_{k+1} = A x_k + B u_k .

At every time step, with measured state x(k), solve

\begin{aligned} \min_{u_0,\dots,u_{N-1}} \quad & \sum_{i=0}^{N-1} \left( x_i^\top Q x_i + u_i^\top R u_i \right) + x_N^\top P x_N \\ \text{s.t.} \quad & x_0 = x(k) \\ & x_{i+1} = A x_i + B u_i, \quad i = 0,\dots,N-1 \\ & u_{\min} \le u_i \le u_{\max} \\ & x_i \in \mathcal{X}, \quad x_N \in \mathcal{X}_f \end{aligned}
SymbolMeaning
Q \succeq 0Stage penalty on state error
R \succ 0Stage penalty on control effort; positive definite keeps the problem strictly convex
PTerminal cost: approximates the cost-to-go after the horizon ends
NPrediction horizon (number of steps)
\mathcal{X}State constraint set (safe region)
\mathcal{X}_fTerminal constraint set

Tuning intuition: raising Q relative to R gives aggressive, fast control; raising R gives gentle, energy-saving control. A longer N gives better performance and a larger feasible region, at higher computational cost.

Batch form and the QP

Eliminating the states turns the MPC problem into a quadratic program (QP) in the stacked inputs alone. Roll the dynamics forward from x_0:

x_i = A^i x_0 + \sum_{j=0}^{i-1} A^{i-1-j} B u_j .

Stack the predictions X = [x_1; \dots; x_N] and inputs U = [u_0; \dots; u_{N-1}]:

X = S_x x_0 + S_u U, \qquad S_x = \begin{bmatrix} A \\ A^2 \\ \vdots \\ A^N \end{bmatrix}, \qquad S_u = \begin{bmatrix} B & 0 & \cdots & 0 \\ AB & B & \cdots & 0 \\ \vdots & & \ddots & \vdots \\ A^{N-1}B & A^{N-2}B & \cdots & B \end{bmatrix}

With block-diagonal weights \bar{Q} = \operatorname{blkdiag}(Q, \dots, Q, P) and \bar{R} = \operatorname{blkdiag}(R, \dots, R), the cost becomes a quadratic in U:

J(U) = U^\top H U + 2\, x_0^\top F^\top U + \text{const}, \qquad H = S_u^\top \bar{Q} S_u + \bar{R}, \quad F = S_u^\top \bar{Q} S_x .

Input and state constraints are linear in U and x_0, so they stack into one inequality:

\min_U \; U^\top H U + 2\, x_0^\top F^\top U \quad \text{s.t.} \quad G U \le w + E x_0 .

H \succ 0 because R \succ 0, so the QP is strictly convex with a unique solution. Only x_0 changes between time steps; H, F, G, w, E can be built once offline.The alternative sparse form keeps the states as decision variables, with the dynamics as equality constraints. It has more variables but a banded structure, and it scales better for long horizons.

Unconstrained case and the link to LQR

Without constraints, MPC reduces to a fixed linear state feedback, and with the right terminal cost it is exactly LQR. Set the gradient of J(U) to zero:

U^\star = -H^{-1} F x_0, \qquad u_0^\star = -\begin{bmatrix} I & 0 & \cdots & 0 \end{bmatrix} H^{-1} F \, x_0 = K_N x_0 .

K_N is a constant matrix, so the receding-horizon law is u = K_N x. Now choose P as the solution of the discrete algebraic Riccati equation (DARE):

P = A^\top P A + Q - A^\top P B \left( R + B^\top P B \right)^{-1} B^\top P A .

Then x^\top P x is the exact infinite-horizon cost-to-go under LQR, and K_N equals the LQR gain K_\infty = -(R + B^\top P B)^{-1} B^\top P A for any N \ge 1. The horizon no longer matters.

Constraints are why MPC exists. With input or state constraints, the optimal law is no longer linear. It is piecewise affine in x: the state space splits into polyhedral regions, each with its own affine law u = K_r x + k_r, one region per set of active constraints . LQR cannot represent this; MPC computes it implicitly by solving the QP online.

Why a finite horizon can fail

Re-solving a finite-horizon problem does not automatically give a stable or even well-defined closed loop. Two failure modes exist.

Instability (myopia). The controller sees only N steps. It may pick inputs that look cheap over the window but push the state somewhere costly or unstable just beyond it. With P = 0 and a short N on an unstable plant, the optimizer can find it cheapest to spend little effort now, and the closed loop diverges. This can happen even without constraints.

Loss of recursive feasibility. The QP has a solution at time k, but the state x(k+1) it produces has no feasible input sequence, so the controller has no valid action. Typical cause: the state drifts toward a constraint boundary that the short horizon cannot see how to escape.

A long enough horizon usually hides both problems in practice, but gives no guarantee. The next section gives the standard design that guarantees both properties for any N, from any state where the first problem is feasible.

Stability recipe: terminal ingredients

Choose the terminal cost P and terminal set \mathcal{X}_f so the optimal cost V_N(x) works as a Lyapunov function. Then the closed loop is recursively feasible and asymptotically stable . The ingredients:

  1. A local controller u = Kx, usually the LQR gain, that stabilizes the unconstrained system.
  2. Terminal cost P = the DARE solution, so x^\top P x is the exact cost-to-go when u = Kx is used forever.
  3. A terminal set \mathcal{X}_f that is positively invariant under u = Kx, inside which Kx satisfies the input and state constraints. Invariant means: if x \in \mathcal{X}_f, then (A + BK)x \in \mathcal{X}_f.

Proof idea: shift and append. Let U^\star = (u_0^\star, \dots, u_{N-1}^\star) be optimal at x, ending at x_N^\star \in \mathcal{X}_f. After applying u_0^\star, the state is x^+ = x_1^\star. Build a candidate for the next problem by dropping the first input and appending the local controller:

\tilde{U} = \left( u_1^\star, \; u_2^\star, \; \dots, \; u_{N-1}^\star, \; K x_N^\star \right).

Recursive feasibility. The first N-1 inputs were already feasible. The appended K x_N^\star is feasible because x_N^\star \in \mathcal{X}_f, and it lands in \mathcal{X}_f again by invariance. So the problem at x^+ has at least one feasible solution.

Cost decrease. The candidate's cost equals V_N(x) minus the first stage cost, plus a change in terminal cost that is \le 0 because P is the LQR cost-to-go. Since the optimum is no worse than the candidate,

V_N(x^+) - V_N(x) \le -\left( x^\top Q x + u_0^{\star\top} R \, u_0^\star \right).

So V_N strictly decreases along closed-loop trajectories, and the origin is asymptotically stable on the set of initially feasible states. The terminal condition used above, required for all x \in \mathcal{X}_f, is

\left( (A+BK)x \right)^\top P \left( (A+BK)x \right) - x^\top P x \le -\left( x^\top Q x + x^\top K^\top R K x \right),

and it holds with equality when P comes from the DARE and K is the LQR gain.Many implementations drop \mathcal{X}_f and use a long N with P from the DARE. Stability then holds only approximately, or for large enough N .

Self-check

Try each question before opening its answer.

Why apply only u_0 instead of the whole optimal sequence?

The rest of the sequence was computed from a prediction, and the prediction is wrong as soon as a disturbance or model error appears. Re-solving from the new measurement closes the loop. Applying the whole sequence would be open-loop control, with no correction for anything the model missed.

No constraints, P = 0, short horizon N. Is the closed loop guaranteed stable?

No. The law is linear, u = K_N x, but K_N comes from a truncated cost that ignores everything after step N. On an unstable or lightly damped plant, A + BK_N can have eigenvalues outside the unit circle. Stability is guaranteed if P is the DARE solution (then K_N = K_\infty for any N), or if N is large enough.

In the shift-and-append argument, why must \mathcal{X}_f be invariant under u = Kx?

The candidate appends K x_N^\star as its last input, so its new terminal state is (A + BK) x_N^\star. For the candidate to be feasible, that state must lie in \mathcal{X}_f again. Invariance is exactly this property. Without it the candidate could break the terminal constraint, and the recursive feasibility proof fails.

Why does R \succ 0 matter for the QP?

It makes H = S_u^\top \bar{Q} S_u + \bar{R} positive definite, so the QP is strictly convex with a unique minimizer. With R = 0, H can be singular, the optimal input may not be unique, and solvers can return erratic, chattering inputs.

When does the horizon N stop mattering?

When no constraints are active and P is the DARE solution. The terminal cost then encodes the exact infinite-horizon tail, so every N gives the LQR law. With active constraints, a longer N enlarges the set of feasible initial states and usually improves performance.

Time-Varying Dynamical Systems

A system is time-varying when its dynamics depend on the clock. This tab compares linear time-varying (LTV) systems with linear time-invariant (LTI) ones and lists which LTI tools survive.

Time-invariant vs time-varying

An LTI system has constant matrices:

\dot{x} = A x + B u.

Shifting an input in time shifts the response by the same amount. Only the elapsed time t - t_0 matters.

An LTV system has matrices that depend on time:

\dot{x} = A(t)\, x + B(t)\, u.

The same input applied at two different times gives two different responses. The start time t_0 matters, not only t - t_0.

Examples: a rocket that loses mass as it burns fuel, a satellite in orbit, components that age, and any nonlinear system linearized along a trajectory rather than at a fixed point.

Why systems vary

Time invariance is an approximation. It holds when the system's parameters change much more slowly than the dynamics you care about. A model needs time dependence when that separation of time scales fails. This happens for six common reasons.

  1. The physical parameters change. A rocket burns fuel and loses mass. A battery's internal resistance rises as it discharges. Friction grows as parts wear, and coefficients drift with temperature.
  2. The environment follows a schedule. A satellite sees a gravity gradient that repeats every orbit. Rotating machinery, tides, seasons and daily power demand are all periodic. A known external schedule makes A(t) and B(t) functions of time, often periodic ones.
  3. Linearization along a trajectory. A nonlinear plant \dot{x} = f(x, u) can be time-invariant and still give an LTV model. Linearizing at a fixed equilibrium gives constant matrices. Linearizing along a moving reference \bar{x}(t), as in tracking or trajectory optimization, gives A(t) = \partial f / \partial x \,|_{\bar{x}(t)}. This is the most common source of LTV models in control.
  4. Hidden slow states. A variable left out of the model, such as an operating point, a load or a context, shows up as parameters that change over time. Gain scheduling and linear parameter-varying (LPV) models make this explicit.
  5. Neural circuits change their own wiring. A common model of a population of neurons is a rate network, \dot{h} = -h + J(t) \tanh(h) + B u(t), where J(t) holds the connection strengths. Those strengths do not stay fixed. Short-term synaptic depression and facilitation change them over milliseconds to seconds. Neuromodulators such as dopamine and acetylcholine shift neuronal gain with arousal and attention. Long-term plasticity rewires the circuit as an animal learns, over hours to days. The same circuit can also route activity differently depending on the task or context. When any of these changes on the time scale of the recorded activity, a fixed-J model is the wrong fit, and J(t) has to vary.
  6. Variation by design. A controller can vary on purpose. A finite-horizon LQR has a gain K(t) that changes as the deadline approaches. Periodic forcing can also stabilize a system that no constant input could: vibrating the pivot of an inverted pendulum fast enough keeps it upright (Kapitza's pendulum).

Rule of thumb: keep an LTI model while the parameters are effectively constant over the time window of interest. Switch to an LTV model when they change on the same time scale as the state.

Solution: the state-transition matrix

For LTI systems, x(t) = e^{A(t - t_0)} x_0. For LTV systems, the matrix exponential is replaced by the state-transition matrix \Phi(t, t_0), defined by

\frac{\partial}{\partial t} \Phi(t, t_0) = A(t)\, \Phi(t, t_0), \qquad \Phi(t_0, t_0) = I.

The full solution is

x(t) = \Phi(t, t_0)\, x_0 + \int_{t_0}^{t} \Phi(t, \tau)\, B(\tau)\, u(\tau)\, d\tau.

\Phi depends on both arguments, not on their difference. It equals \exp\left(\int_{t_0}^{t} A(\tau)\, d\tau\right) only when the matrices A(t) commute with each other at all times. In general there is no closed form, and \Phi is computed numerically.

Stability: eigenvalues are not enough

An LTI system is asymptotically stable if and only if every eigenvalue of A has a negative real part. For LTV systems, the matching statement is false: every frozen-time A(t) can have stable eigenvalues while the system diverges.

The Markus–Yamabe example shows this:

A(t) = \begin{bmatrix} -1 + 1.5 \cos^2 t & 1 - 1.5 \sin t \cos t \\ -1 - 1.5 \sin t \cos t & -1 + 1.5 \sin^2 t \end{bmatrix}.

For every t, the eigenvalues of A(t) are -0.25 \pm i\sqrt{7}/4. Yet x(t) = e^{t/2} \begin{bmatrix} -\cos t & \sin t \end{bmatrix}^\top is a solution, and it grows without bound.

Tools that do work for LTV stability:

  • Lyapunov functions V(x, t) that depend on time.
  • Bounds on \Phi: exponential stability holds when \|\Phi(t, t_0)\| \le c\, e^{-\lambda (t - t_0)} for some c, \lambda > 0.
  • Slow variation: frozen-time eigenvalues do imply stability when A(t) changes slowly enough, for example with \|\dot{A}(t)\| small.

Because t_0 matters, LTV stability also has a uniform version. Uniform stability requires the constants c and \lambda to be the same for every start time t_0. For LTI systems, stability is always uniform.

Lipschitz Dynamics

A system has Lipschitz dynamics when nearby states always move at similar velocities. This one condition gives unique trajectories, bounded sensitivity to initial conditions, and the contraction tools used to prove stability. This tab starts from the basics and builds up to learned dynamics.

Start here: the basics

What a dynamical system is. A state x (a number or a vector) changes over time by a rule

\dot{x} = f(x).

Read it as: at state x, the velocity is f(x). Pick a start x(0), follow the velocities, and you trace a trajectory x(t). For \dot{x} = -2x, the velocity at x = 1 is -2 and at x = 0.5 it is -1, so the state slides toward 0. The solution is x(t) = x(0)\, e^{-2t}.

What Lipschitz means. f is Lipschitz with constant L if the gap between two outputs is never more than L times the gap between the inputs:

|f(x) - f(y)| \le L\, |x - y| .

In one dimension, every chord of the graph of f has slope at most L in size. It is a speed limit on how steeply f changes: no jumps and no vertical tangents.

Two quick examples. For f(x) = -2x, |f(x) - f(y)| = 2|x - y|, so L = 2. For f(x) = \sin x, the slope \cos x never exceeds 1 in size, so L = 1.

Why it matters for dynamics. Start two trajectories close together. If f is Lipschitz, their velocities are close too, so they cannot suddenly fly apart. With starts 1.0 and 1.1 (gap 0.1):

SystemLGap at time tGap at t = 1
\dot{x} = -2x20.1\, e^{-2t} (shrinks)0.0135
\dot{x} = 2x20.1\, e^{2t} (grows)0.739
Any system with L = 22at most 0.1\, e^{2t}at most 0.739

The gap can shrink or grow, but never faster than e^{Lt}. That guarantee gives three things, each covered below: uniqueness (a start determines exactly one future), predictability (small errors stay controlled over finite time), and stability tools (a signed version of L tells you when all trajectories converge).

Notation. \|x\| is the length of a vector. \sup is the largest value (strictly, the least upper bound). Df(x) is the Jacobian, the matrix of partial derivatives, which plays the role of the slope in several dimensions.

Lipschitz continuity

For \dot{x} = f(x, t) on a domain D, f is Lipschitz in x with constant L if, for all t,

\| f(x, t) - f(y, t) \| \le L\, \| x - y \| \qquad \forall\, x, y \in D .

The smallest such L is the Lipschitz constant.

  • Global: one L works on all of \mathbb{R}^n. Linear f(x) = Ax has L = \|A\|, the induced matrix norm.
  • Local: every point has a neighborhood with its own finite L. Every C^1 function is locally Lipschitz.
  • Jacobian test: on a convex set, the best constant is L = \sup_{x \in D} \|Df(x)\|.
FunctionLipschitz?Why
AxGlobally, L = \|A\|Linear, bounded derivative

\operatorname{ReLU}(x)Globally, L = 1Not differentiable at 0, but slopes are 0 or 1

The chain of strength: continuously differentiable implies locally Lipschitz, which implies continuous. Neither converse holds.

Existence and uniqueness

Picard–Lindelöf theorem. If f is continuous in t and Lipschitz in x near (x_0, t_0), then \dot{x} = f(x, t), x(t_0) = x_0 has exactly one solution on some interval [t_0 - h, t_0 + h] .

The proof rewrites the ODE as an integral equation and iterates it:

x_{k+1}(t) = x_0 + \int_{t_0}^{t} f\big(x_k(s), s\big)\, ds .

Each iteration shrinks the gap between successive guesses by a factor Lh. For Lh < 1 the map is a contraction, and the Banach fixed-point theorem gives one unique fixed point: the solution.

  • Local Lipschitz gives a unique solution that may still blow up in finite time. \dot{x} = x^2, x(0) = 1 gives x(t) = 1/(1 - t), which escapes at t = 1.
  • Global Lipschitz rules out blow-up: the solution exists for all t.
  • Continuity alone (Peano's theorem) gives existence but not uniqueness.

Counterexample. \dot{x} = \sqrt{|x|}, x(0) = 0. The right-hand side is continuous but not Lipschitz at 0. Both x(t) = 0 and x(t) = t^2/4 solve it. The state can also rest at 0 for any time c and then leave along (t - c)^2/4, so there are infinitely many solutions.

Grönwall and sensitivity

Two trajectories of an L-Lipschitz system separate at most like e^{Lt}. The tool behind this is Grönwall's inequality: if u(t) \ge 0 and

u(t) \le a + L \int_{t_0}^{t} u(s)\, ds \quad\Longrightarrow\quad u(t) \le a\, e^{L (t - t_0)} .

Continuous dependence on initial conditions. Let x(t) and y(t) solve the same system and set e(t) = \|x(t) - y(t)\|. The integral form and the Lipschitz bound give e(t) \le e(t_0) + L \int e(s)\, ds, so

\| x(t) - y(t) \| \le \| x(t_0) - y(t_0) \|\, e^{L (t - t_0)} .

Perturbed vector field. If y solves \dot{y} = g(y, t) with \|f - g\| \le \varepsilon everywhere, then

\| x(t) - y(t) \| \le \| x(0) - y(0) \|\, e^{L t} + \frac{\varepsilon}{L} \left( e^{L t} - 1 \right) .
  • The bound is finite for every finite t, so the flow map is continuous (in fact Lipschitz) in x_0.
  • It is a worst case. L bounds the largest local stretching rate, so a stable system can still have a large L.
  • The largest Lyapunov exponent is at most L. Chaos needs a positive exponent; a finite L only caps how fast neighbors diverge.
  • Error bounds for Euler and Runge–Kutta integrators carry an e^{LT} factor from this same argument.

One-sided Lipschitz and contraction

The constant L only bounds divergence. A signed version can also prove convergence, which makes it the right tool for stability. f has one-sided Lipschitz constant \nu if

\big\langle f(x) - f(y),\, x - y \big\rangle \le \nu\, \| x - y \|^2 \qquad \forall\, x, y .

\nu can be negative, and \nu \le L always. The same Grönwall argument gives

\| x(t) - y(t) \| \le e^{\nu t}\, \| x(0) - y(0) \| .

If \nu < 0, every pair of trajectories converges exponentially at rate |\nu|. The system contracts.

Logarithmic norm. For differentiable f, \nu = \sup_x \mu(Df(x)), where the log norm (matrix measure) is

\mu(A) = \lim_{h \to 0^+} \frac{\|I + hA\| - 1}{h}, \qquad \mu_2(A) = \lambda_{\max}\!\left( \tfrac{A + A^\top}{2} \right) .
Norm\mu(A)
2-normLargest eigenvalue of (A + A^\top)/2
1-norm\max_j \big( a_{jj} + \sum_{i \ne j} |a_{ij}| \big) (columns)
\infty-norm\max_i \big( a_{ii} + \sum_{j \ne i} |a_{ij}| \big) (rows)

Contraction theorem. If \mu(Df(x, t)) \le -c < 0 for all x and t, all trajectories converge to each other exponentially at rate c . For an autonomous system, this means a unique, globally exponentially stable equilibrium. A weighted norm \|\Theta x\| (a contraction metric) widens the test.

  • Eigenvalues of Df at one point give only local stability. \mu(Df) < 0 everywhere gives global convergence.
  • No equilibrium needs to be found first. Contraction is a property of the vector field.
  • Example: \dot{x} = -x + W \tanh(x) + u(t) has \mu_2(Df) \le -1 + \|W\|_2, so it contracts when \|W\|_2 < 1, for any input u(t).

This links to the Time-Varying Dynamical Systems tab: frozen-time eigenvalues can mislead, but \mu(A(t)) \le -c for all t is a sufficient condition for uniform exponential stability of \dot{x} = A(t) x. The Markus–Yamabe matrix there fails this test.

Lipschitz bounds in learned dynamics

In RNNs and neural ODEs, the Lipschitz constant decides whether trained dynamics are well posed, stable and robust. Constants multiply under composition, and tanh and ReLU are 1-Lipschitz, so

L\big(\sigma \circ W_k \circ \cdots \circ \sigma \circ W_1\big) \le \prod_{i=1}^{k} \| W_i \|_2 .

The bound is usually loose, but it is cheap and differentiable.

ModelDynamicsRole of the Lipschitz constant
Neural ODE \dot{x} = f_\theta(x, t)Lipschitz f_\theta gives a unique flow, so the adjoint method is valid
Vanilla RNNh_{t+1} = \tanh(W h_t + U x_t)\|W\|_2 < 1 makes the update a contraction (echo-state property): old inputs fade
Continuous-time RNN\tau \dot{h} = -h + W \phi(h) + uContracts when \|W\|_2\, L_\phi < 1
Lipschitz RNN \dot{h} = A h + \tanh(W h + U x + b)A and W built from symmetric and skew-symmetric parts to bound the hidden-state Jacobian

Ways to enforce a small constant:

  • Spectral normalization : divide W by a power-iteration estimate of \|W\|_2, giving L \le 1 per layer.
  • Orthogonal weights: \|W\|_2 = 1 exactly, so gradients neither explode nor vanish through the linear part.
  • Jacobian regularization: penalize \|Df(x)\|_F^2 on training data.
  • Skew-symmetric weights: W = M - M^\top has purely imaginary eigenvalues, so the linear part neither grows nor decays.

The trade-off. A small L or negative \nu makes a model stable and robust but limits memory. A contracting RNN forgets its initial state at rate e^{-ct}, so tasks with long dependencies push it toward the edge of stability, \nu \approx 0.

Self-check

Try each question before opening its answer.

What is the Lipschitz constant of f(x) = 3\sin x - x on \mathbb{R}?

f'(x) = 3\cos x - 1 ranges over [-4, 2], so L = \sup |f'(x)| = 4, reached at x = \pi.

Why does \dot{x} = \sqrt{|x|} from x(0) = 0 have many solutions, while \dot{x} = \sqrt{|x|} from x(0) = 1 has one?

Uniqueness needs a Lipschitz bound only near the trajectory. Near x = 1, \sqrt{x} is smooth with bounded slope, so Picard–Lindelöf applies. At x = 0 the slope is unbounded, and the theorem gives nothing.

\dot{x} = -x has L = 1, and Grönwall allows the gap to grow like e^{t}. Is that what happens?

No. The gap shrinks like e^{-t}. L ignores direction, so the bound is a loose worst case. The one-sided constant is \nu = -1, which gives the exact rate.

Every eigenvalue of Df(x) has negative real part at every x. Does the system contract?

Not necessarily. Contraction needs \mu(Df) < 0, which is stronger than stable eigenvalues. For example, A = \begin{bmatrix} -1 & 10 \\ 0 & -1 \end{bmatrix} has both eigenvalues at -1 but \mu_2(A) = -1 + 5 = 4 > 0, so some distances grow at first.

Why can a strongly contracting RNN struggle with long-memory tasks?

Contraction makes every trajectory forget its start at rate e^{-ct}, so information about early inputs decays exponentially. Long memory needs \nu near 0, where the dynamics neither forget fast nor blow up.
